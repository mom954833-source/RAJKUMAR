SECURITY SPECS

Honest, Cryptographic Security

We believe in verifiable cryptography over marketing hyperbole. No "100% unhackable" buzzwords—just solid engineering.

Cryptographic Salt & Hashes

Passwords and PINs are hashed using SHA-256 combined with a 256-bit cryptographically secure random salt (CSPRNG). Never stored in plain text.

Isolated Room SQLite Database

Protected app metadata and security event logs are sequestered in an encrypted sandboxed Room database accessible only by the VaultHide process.

Progressive Lockout Defense

Automatic 30-second cooldown protection kicks in after 5 consecutive incorrect authentication attempts to thwart automated brute-force attacks.

Zero External Telemetry

Zero cloud servers. Zero analytics trackers. Zero third-party advertising SDKs. Your secrets never leave your device.

PRIVACY FIRST

Privacy Policy Summary

What we access, what we store, and how your data is protected.

1. Information Accessed

VaultHide only queries package names of installed launcher apps to allow you to protect them. We do not access files, chat logs, photos, or passwords of other apps.

2. Permissions Required

USE_BIOMETRIC for fingerprint/face authentication and VIBRATE for haptic feedback. No access to location, camera, or microphone.

3. Local Storage Only

All hashes and lists are kept exclusively on local device memory in Room SQLite. Zero bytes are sent to any remote server.

4. User Data Erasure

Users can execute a complete, irreversible data wipe at any time via the "Reset Vault" option in Security Settings.
